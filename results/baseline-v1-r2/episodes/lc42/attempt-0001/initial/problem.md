# Trapping Rain Water

An array gives nonnegative heights of unit-width columns. Return the total amount of water retained between the columns after rain; water escapes beyond the two ends.

Constraints: 1 <= len(height) <= 20000; 0 <= height[i] <= 100000.

Interface: {"height": [integers]} -> JSON integer
Read one JSON value from stdin and print exactly one JSON value to stdout.
Implement solution.py. Run the provided tests with: python test.py
