# Search in Rotated Sorted Array

data["nums"] is a rotation of a strictly increasing integer array. Return the zero-based index of data["target"], or -1 when it is absent. Aim for logarithmic search.

Constraints: 1 <= len(nums) <= 5000; distinct elements; values and target in [-10000,10000].

Interface: {"nums": [integers], "target": integer} -> JSON integer
Read one JSON value from stdin and print exactly one JSON value to stdout.
Implement solution.py. Run the provided tests with: python test.py
