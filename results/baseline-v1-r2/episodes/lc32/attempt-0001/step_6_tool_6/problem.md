# Longest Valid Parentheses

For a string consisting of parentheses, return the length of its longest contiguous substring that is a correctly balanced parenthesis sequence. An empty string has answer 0.

Constraints: 0 <= len(s) <= 30000; characters are ( and ).

Interface: {"s": string} -> JSON integer
Read one JSON value from stdin and print exactly one JSON value to stdout.
Implement solution.py. Run the provided tests with: python test.py
