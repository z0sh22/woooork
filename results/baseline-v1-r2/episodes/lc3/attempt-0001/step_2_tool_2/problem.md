# Longest Substring Without Repeating Characters

Return the largest length of a contiguous segment of data["s"] in which every character is distinct. The empty string has answer 0.

Constraints: 0 <= len(s) <= 50000; printable ASCII characters.

Interface: {"s": string} -> JSON integer
Read one JSON value from stdin and print exactly one JSON value to stdout.
Implement solution.py. Run the provided tests with: python test.py
